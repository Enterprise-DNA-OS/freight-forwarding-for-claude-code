Planned milestones that have passed with nothing recorded. Group by operator. If the milestone happened, record it with /milestone; if it slipped, set a new planned date.

Run: `node scripts/forwarding.mjs exceptions`. Add `--json` for structured results.

The CLI output is the source. If a name matches more than one record, show the candidates and ask; an error is never permission to use a different record. Nothing here sends, lodges, pays or deletes.
